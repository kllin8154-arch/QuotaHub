# Agnovexa One · 自主执行任务指令（v0.13.0）

## 身份与目标
你是负责 Agnovexa One 的产品工程负责人、Electron 桌面工程师和 QA。不要把已绑定账号误认为实时数据，不要把 Google OAuth 身份误当作其他平台的授权。保持精致玻璃态、桌面悬浮、卡片/横条/侧栏、悬浮球/贴边/灵动岛功能，按最少必要代码迭代。

## 本轮必须闭环
1. 排除 Fixture QA 隔离测试进程对正式屏幕的干扰，隔离测试数据且不得复制到正式目录。
2. 同一个正式用户数据目录只允许一个 Agnovexa One 写入实例；重复启动仅唤起窗口。
3. 不重复打开控制台；用户主动打开时才显示完整看板。
4. DeepSeek、ChatGPT 及已绑定 API/中转站连接继续使用已有本地会话，保留数据；不自动获取任何其他平台的第三方身份令牌。
5. 90 秒采样。最近 5 分钟内成功采集才标为“同步正常”；否则明确区分“采集异常”“数据过期”“等待首次采样”，保留最后有效值并标记非实时。
6. 数据状态同时覆盖全屏看板、桌面组件、历史图表；折线图与变化柱状图只使用真实带时间戳的采样数据。
7. 启动、最小化、关闭/重启后的会话存续进行实际测试；保存 D 盘用户数据备份，不改动 OAuth 原件与真实账号登录凭证。
8. 交付新的 Windows 免安装程序、桌面快捷方式，并公开同步可复用的源码和测试，公开仓库不含客户端私钥/会话/历史余额。

## 验收门槛
- 编译、Google OAuth、平台监测、身份关联、同步健康度单元测试全部通过。
- 在隔离目录里运行封包后的 EXE 验证，而非只检查源码。
- 再次打开同一桌面程序不会增加第二个写入实例。
- 旧测试窗不再显示在用户桌面；真实目录此前的两个监测账号仍可被识别，数字不被测试数据覆盖。
- GitHub 可见对应版本，工作区干净；不把单次采样说成服务器推送的毫秒级实时数据。
